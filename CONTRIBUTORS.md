## How to Sign In as a Contributor

We welcome contributions of all kinds—bug fixes, documentation, language design, performance benchmarks, and ecosystem packages.

Contributors are **automatically detected and added to this roll upon merging into `main`**.

To explicitly specify your preferred display name, GitHub handle, or role description:

1. Add or edit your entry in [`.github/contributors-meta.json`](.github/contributors-meta.json):
   ```json
   {
     "name": "Your Name",
     "github": "yourhandle",
     "role": "Documentation / Contributor",
     "contributions": "Summary of your work"
   }
   ```
2. Run `node tools/generate-contributors.js` (or let CI update it automatically).
3. Submit a pull request.
