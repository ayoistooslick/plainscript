Getting started with PlainScript 2.1

PlainScript is a statically typed language that compiles to JavaScript. You write a .pln file, the compiler checks it, and you run the emitted ES module with Node, Vite, Next.js or any other JavaScript toolchain.

This guide uses the 2.1 dialect. If you have a 2.0 codebase, read Migrating from 2.0; nothing breaks until you add the pragma.

3. Bindings

value binds a name that cannot be reassigned; set binds one that can; change assigns to an existing mutable binding.

Locals are checked. Assigning to a value is a compile error, and so is using a name that was never declared.

4. Types and functions

Types are written after a colon in a parameter list, and a function's result follows returns.

|> is the pipeline operator: the value on the left becomes the first argument of the call on the right.

5. Conditionals and loops

Every block closes with end. Indentation is for readers; the compiler uses end.

6. Optional values and errors

T? is T or nothing. Narrow it with is nothing before using it. Errors are handled with try, catch and finally; throw takes any value.

7. Modules and npm packages

A .pln file is an ES module. Relative imports use .pln paths and are emitted with .js; package and Node built-in imports pass through unchanged.

Packages without TypeScript declarations are any at the boundary. Add declare statements for the parts you rely on, or keep the values in explicitly typed PlainScript code as soon as possible.

8. A project

plainscript new writes a project:

The default project has src/main.pln, a package.json with a build script, and a plainscript.config.json that maps src/ to dist/.

plainscript build reads the config, compiles the module graph and writes one ES module per source file. plainscript watch rebuilds on change.
