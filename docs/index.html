PlainScriptVol. 2.1An independent languageMMXXVI

A language that reads like plain writing.

PlainScript is a statically typed, full-stack language for the JavaScript platform. Write modules that read like structured English; compile them to ordinary ES modules that run anywhere JavaScript already runs. This is the manual — the whole thing, in the open.

Plate 01The language

Readable at the source. Ordinary at the output.

No new runtime, no virtual machine, no ecosystem to migrate to. PlainScript is a typed surface over the JavaScript platform: the compiler checks your program, then emits modules your existing tools already understand.

  • Statically checked before anything runs.
  • Functions, records, unions and async without ceremony.
  • Ships with a CLI, language server, formatter and debugger.
  • One file at a time — 2.0 code keeps compiling.
#syntax 2.1

import { print } from "std/io"

define greet(name: text) returns text
    return "Hello, {name}."
end

print(greet("world"))
import { print } from "./std/io.js";

function greet(name) {
  return `Hello, ${name}.`;
}

print(greet("world"));
$ plainscript run hello.pln
Hello, world.

PositionWhat this is, and is not
01

Independent by design

PlainScript is not a framework or a wrapper. It is a language with its own grammar, checker and compiler, built in the open by one author and published under MIT.

02

Typed without ceremony

Types are inferred where they are obvious and written where they matter. The checker is strict about the things that break software, and quiet about the rest.

03

Ordinary at the output

The compiler emits readable ES modules and source maps. There is no runtime to adopt and no ecosystem to leave behind.
