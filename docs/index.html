A language for serious JavaScript software

Make the machine readable.

PlainScript 2.1 is a statically typed language that reads like structured English and compiles to ordinary JavaScript modules. Learn the syntax, understand the compiler, and build full-stack applications without leaving the ecosystem.

Start with the shape of the language.

Read the quick tour, then move into the specification when you need exact semantics. The docs are organized for both paths.

plainscript new my-app
01 / BUILD

Install and run

Use the CLI to check, build, format, test, and scaffold a project.

02 / LEARN

Learn the language

Follow the language model from modules and types to async code and rendering.

03 / UNDERSTAND

Explore the compiler

Trace source through lexer, parser, checker, HIR, and JavaScript emission.
