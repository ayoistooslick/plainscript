Quick start

Check first, then build.

01

Write

Create a .pln file with readable declarations and blocks.

02

Check

Run plainscript check file.pln to validate imports and generated JavaScript.

03

Build

Run plainscript build to emit standalone files in dist/.

npx plainscript-lang new hello
cd hello
npx plainscript-lang check
npx plainscript-lang build
npm start

Language

A focused grammar for real programs.

Variables

remember name as "Ada" and readable assignment with becomes.

Conditions

Use is at least, is equal to, contains, and is in list.

Functions

Define functions with make, return with give, and close with done.

Loops

Repeat loops: repeat 5 times, repeat with item in list, and repeat while.

Records

Model data with record kinds, field defaults, and readable constructors.

Web apps

Declare routes, JSON responses, sessions, cookies, uploads, and auth.

Data and async

Use SQLite, HTTP, files, schedules, concurrency, and WebSockets.

Native & Wasm

Target Node.js, ES Modules, standalone executables, and WebAssembly.

AI integration

High token efficiency (50% reduction) with OpenAI-compatible completion APIs.
