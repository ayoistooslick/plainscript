Quick start

A simple three-step workflow.

01

Write

Create a .pln file with readable code blocks.

02

Check

Run plainscript check file.pln to catch mistakes.

03

Build

Run plainscript build to get your files in dist/.

npx plainscript new hello
cd hello
npx plainscript check
npx plainscript build
npm start

Language

A small set of words you already know.

Variables

Store values with remember name as "Ada" and change them with becomes.

Conditions

Compare things with is at least, contains, between, and more.

Functions

Create functions with make, return with give, and close with done.

Records

Model your data with record kinds and easy constructors.

Modules

Import code with bring ... from, @/ aliases, and re-exports.

Compound Types

Use dictionaries, sets, and tuples with unpacking.

Web apps

Set up routes, JSON responses, sessions, cookies, uploads, and auth.

Data and async

Work with SQLite, HTTP, files, schedules, concurrency, and WebSockets.

AI providers

Call Groq and other OpenAI-compatible providers using your own keys.
