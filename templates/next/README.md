# Next.js starter

A Next.js App Router page whose React Server Component is written in PlainScript.

```bash
npm install
npm run dev
```

`npm run build:plain` compiles `app/Home.pln` to an ordinary ES module and `app/page.js`
renders it. The output uses Next's normal React runtime; there is no Next-specific
PlainScript plugin.

```bash
npm run check
npm run build
```
